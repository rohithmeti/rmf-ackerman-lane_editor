6 · Export

How to use

  1. Load the map. Check the robot size (section 2).
  2. Auto layout puts a lane along every aisle between racks plus a lattice on open floor. Tags that cannot fit the spot-turn circle or lanes that are too narrow are dropped automatically (red ✕).
  3. Fix by hand: Draw lane (press, drag, release: it snaps to horizontal / vertical and to existing nodes), Erase area (drag a rectangle), Delete lane. Lanes can only be horizontal or vertical; every crossing becomes a tag, so lanes never cross mid-lane.
  4. Set the simulator frame (section 4), then export. Wheel = zoom, right / middle drag = pan.
